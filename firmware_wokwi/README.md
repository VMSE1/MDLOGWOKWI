# MADILOG: имитация модуля на STM32 в Wokwi

Прошивка для **Nucleo-C031C6**: раз в секунду печатает в порт строку

    FRAME,a501000001ab000a018100d3e0c2125e28,142.5

Это кадр на 17 байт (формат из `sim/packet.py`) и дальность в метрах. Первая строка совпадает с тестовым примером из документа.

Почему C031, а не G474: Nucleo-G474RE в Wokwi не поддерживается. Поддерживаются Nucleo-C031C6, Nucleo-L031K6 и Blue Pill. Код кадра, CRC16 и подписи в `src/frame.c` не привязан к плате и переносится на G474 без изменений. Работа с портом (`src/main.c`) на G474 пишется заново.

## Что проверено

- Код кадра, CRC16 и подписи HMAC-SHA256 собран и запущен на обычном компьютере (`make test`): подпись `d3e0c212` и весь кадр совпадают с кодом симулятора.
- Прошивка под Cortex-M0+ собирается без ошибок (около 3,4 КБ), готовые файлы лежат в `build/`.
- Прошивка прогнана в эмуляторе ядра Cortex-M0+ (`make emu`, нужен `pip install unicorn pyelftools`): печатает те же строки `FRAME`, кнопка включает подмену и светодиод. Периферия в эмуляторе заглушена, электрику он не проверяет.
- **Внутри самого Wokwi прошивка не запускалась.** Работу порта, кнопки и светодиода нужно проверить у себя (см. ниже). Настройки порта PA2/PA3 (AF1) взяты по справочной документации, скорость порта считается от тактовой частоты.

## Запуск в Wokwi

1. Установите VS Code и расширение **Wokwi Simulator** (потребуется вход в аккаунт Wokwi; условия лицензии проверьте на сайте).
2. Откройте эту папку в VS Code. Файлы `build/madilog.elf` и `build/madilog.hex` уже собраны.
3. F1, затем «Wokwi: Start Simulator». В окне Serial Monitor должны идти строки `FRAME,...`.
4. Кнопка (красная, клавиша `s` или клик мышью) включает режим «подмена»: подпись становится неверной, горит светодиод.

## Сборка заново

Нужен `arm-none-eabi-gcc` (Linux: `sudo apt install gcc-arm-none-eabi`, Windows: ARM GNU Toolchain). Затем `make`. Проверка кадра на компьютере: `make test`.

## Подключение к серверу

В `wokwi.toml` включена пересылка порта: `rfc2217ServerPort = 4000`. Готовый мост: `python tools/serial_bridge.py --port rfc2217://localhost:4000` из корня репозитория (подробно в `docs/ПЛАТА_и_подключение.md`). Вручную порт читается так:

    import serial
    port = serial.serial_for_url("rfc2217://localhost:4000", baudrate=115200)
    line = port.readline().decode().strip()      # FRAME,<hex>,<дальность>

Для настоящей платы вместо адреса указывают COM-порт, остальной код не меняется. Вкладка симулятора в VS Code должна быть видна, иначе симуляция встаёт.

## Состав

- `src/frame.c`, `src/frame.h` — CRC16, SHA-256, HMAC, сборка кадра (без привязки к плате);
- `src/main.c` — порт, кнопка, светодиод, цикл (для Nucleo-C031C6);
- `test/host_test.c` — проверка на компьютере;
- `vendor/` — файлы запуска и описание регистров из открытого примера Wokwi для C031 (лицензия MIT автора примера и лицензия ST внутри заголовков);
- `diagram.json`, `wokwi.toml` — схема и настройки Wokwi.

Дальность в этой версии имитируется (ходит от 20 до 300 м). Потенциометр на АЦП и настоящий датчик — следующие шаги.
